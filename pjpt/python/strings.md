# Strings

## Creating Scripts

```bash
# Open editor in background (can still use terminal)
mousepad first.py &
```

## Basic Python Structure

```python
#!/bin/python3

# This is a comment
print("Hello, world!")
```

The shebang (`#!/bin/python3`) tells Linux which interpreter to use.

## String Types

```python
# Single quotes
print('Hello')

# Double quotes
print("Hello")

# Multi-line (triple quotes)
print("""Hello,
this spans
multiple lines""")
```

## String Concatenation

```python
print("This string is" + " Awesome")
```

## Special Characters

- `\n` - New line

## Comments

```python
# Single line comment

'''
Multi-line
comment
'''

"""
Also works
for multi-line
"""
```
